# Zethembe Ndwandwe — Engineering Portfolio

A static professional portfolio built for GitHub Pages. No build tools or frameworks are required.

## Before publishing

1. Open `index.html`.
2. Search for `YOUR_EMAIL_HERE` and replace it with your professional email address.
3. Review dates and wording and update anything you want public.
4. Optional: add a PDF CV to this folder and add a button linking to it, e.g. `href="Zethembe_Ndwandwe_CV.pdf"`.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `zethembe-portfolio`.
2. Upload **the contents of this folder** (`index.html`, `styles.css`, `script.js`, and `assets`) to the repository root.
3. Commit the files.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will show the public site address after deployment.

For a personal root site such as `username.github.io`, name the repository exactly `username.github.io`.

## Files

- `index.html` — site content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, reveal effects, current year
- `assets/favicon.svg` — custom ZN favicon

The site is responsive and uses only HTML/CSS/JavaScript, so it is suitable for GitHub Pages.
